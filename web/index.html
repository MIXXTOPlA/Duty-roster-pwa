데이터 백업·복원

업데이트 시 기기 저장 데이터를 유지합니다. 브라우저 데이터 삭제·기기 변경에 대비해 백업 파일을 보관하세요. 백업에는 인원 이름·휴가·근무표가 포함되므로 외부에 공유하지 마세요.

인원 관리

인원 정보는 이 기기에만 저장됩니다. 이미 편성된 인원은 삭제하거나 보직을 변경할 수 없습니다.

이름보직기수관리

휴가·외출 관리

시작·종료 시각 사이에는 근무를 배정하지 않습니다. 휴가 출영 전 마지막 근무에는 OUT이 표시됩니다. 일정을 변경한 후에는 자동 편성을 다시 실행하세요.

인원유형시작종료관리

필수 보직: 분대장·조종수·M60·소총수. 통신병·예비 조종수는 4조 간격과 근무 균형을 개선할 때 활용하는 선택 보직입니다. 같은 사람의 선택 보직 연속 배정은 피하고 다음 근무에서 원래 보직으로 돌아가도록 우선합니다. 빈 필수 칸은 '미배정'으로 표시합니다. 이름 뒤 숫자는 직전 근무와의 간격(4조는 생략), OUT은 등록된 휴가 출영 전 마지막 근무입니다. 첫 근무처럼 이전 기록이 없으면 간격을 표시하지 않습니다.

인원별 근무 통계 월~일 7일 기준 · 다음 월요일 별도

인원보직주간 합계8일 합계오전오후석간열셋말번야간전체 근무시간(h)3조 간격

주간 횟수·유형별 횟수·야간 횟수는 월~일 7일 기준입니다. 전체 근무시간과 8일 합계는 다음 월요일까지 포함한 8일간의 모든 배정을 계산합니다. 3조 간격은 현재 8일 배정 기준입니다. 8~9회는 목표이며 미달·초과가 있어도 하드 오류로 계산하지 않습니다.

개발 단계 제한 사항

현재 자동 편성기는 JavaScript 휴리스틱입니다. WASM 최적화 솔버, 실기기 검증, 개별 근무 편집은 아직 구현되지 않았습니다. 휴가·외출 등록 후 기존 근무표는 자동 갱신되지 않으며 재편성이 필요합니다. 실제 근무에 사용하지 마세요. 데이터는 기기별로 저장되며 브라우저 저장 공간을 지우면 사라질 수 있습니다.
