# Duty Roster PWA

Offline-first experimental duty roster generator for iPad, iPhone and Android.

**Status:** deployment setup in progress. The application source has not yet been uploaded. Do not use for operational duty assignments.

To deploy, upload the contents of the `duty-roster-engine` folder from the v0.9 pages-ready archive into the repository root, preserving `web/`, `src/`, `examples/`, and `.github/workflows/pages.yml`.

Once files are uploaded, enable **Settings → Pages → Build and deployment → GitHub Actions**.
